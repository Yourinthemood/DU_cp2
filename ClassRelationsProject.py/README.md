# Gradebook System

A simple gradebook management system that allows teachers to manage courses, students, and grades.

## Features

- Create courses with teacher names and class size limits
- Add students to courses with their grade level
- Record grades for assignments
- View course details including enrolled students and class average
- View grade statistics including highest grade, lowest grade, and grade distribution
- Track student academic status based on their overall average
